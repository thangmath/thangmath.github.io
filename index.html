3️⃣ Hướng dẫn cài cấu hình cơ bản cho Kodi

1. Cài đặt ⚙ → File Manager → Cột bên phải → Mở Profile directory...
2. Cột bên trái → Add source →
- Nếu tải 2 file: → Browse → External storage → OK → OK → Trỏ tới file đã tải
1-Thiết_lập_môi_trường_Profile_directory.zip
2-Cài_đủ_tiện_ích_Dữ_liệu_Kodi.zip
- Nếu không tải: → Enter path... → Nhập link https://thangmath.github.io → Nhập tên → OK → Trỏ tới nguồn vừa thêm
3. Mở file zip → Chọn phiên bản → Giữ rồi chọn Sao chép
Cài 2 lần cho 2 file: File 1 copy to Profile directory..., file 2 sao chép vào Dữ liệu Kodi
- Android: Bấm home, buộc dừng ứng dụng
- webOS LG: Giữ back 5s
4. Cài thêm các addons qua file zip dùng nguồn "Anh Thăng"
Addons_Tiện_ích/ Data_Dữ_liệu/ Repository_Kho_lưu_trữ/
