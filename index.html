Hướng dẫn cài cấu hình và addons cho Kodi
1. Thêm link vào trình quản lý tập tin cho Kodi. Cột bên phải: Thêm nguồn "thư mục gốc thiết bị" (Android thì chọn trên giao diện, webOS LG thì nhập đường dẫn là /), sau đó mở ra Cấu_hình_lần_đầu.zip
2. Cột bên trái: Mở file Cấu_hình_lần_đầu.zip, chọn phiên bản, giữ rồi chọn Sao chép. Sau đó phải buộc dừng ứng dụng (webOS thì giữ back 5s) https://thangmath.github.io
3. Cài thêm các addons qua file zip dùng nguồn "Anh Thăng" Addons_Tiện_ích/ Data_Dữ_liệu/ Repository_Kho_lưu_trữ/
